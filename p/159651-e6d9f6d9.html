<프로젝트 진단>
공고에 적힌 현재 상태는 기능 개발이 끝났고 남은 일이 실행 환경과 마감 작업이라는 것입니다. Django·PostgreSQL로 만든 서비스를 외부 서버로 옮기고, Docker로 실행 단위를 고정하고, CI를 붙여 배포를 반복 가능하게 만들고, 화면 컴포넌트와 랜딩 페이지를 마무리하는 구성입니다. 기존 기능 수정과 신규 기능 개발이 빠져 있다는 점이 이 공고의 성격을 결정합니다. 5일·100만원은 위 네 가지를 동시에 처리하라는 조건이고, 순서를 잘못 잡으면 마지막 날에 배포만 남습니다. 그래서 배포를 첫날에 끝내고 나머지를 뒤에 붙이는 순서로 계획했습니다.

<작업 범위>
진행할 범위
1) 서버 이전·배포: 운영 서버 준비, Django 애플리케이션·정적 파일·미디어 경로 정리, PostgreSQL 이관 및 접속 설정, Dockerfile·docker-compose 작성, HTTPS·도메인 연결, 배포 절차서 1부.
2) CI: 저장소에 빌드·테스트·배포 파이프라인 구성, 브랜치 기준 자동 배포 규칙 정의, 실패 시 롤백 방법 문서화.
3) 화면 마무리: 공고에 적힌 "화면 컴포넌트 마무리" 범위에서 반응형 깨짐·오탈자·링크 오류 정리. 신규 화면 설계는 포함하지 않습니다.
4) 랜딩 페이지: 1페이지 제작(반응형), 기존 서비스와 링크 연결. 카피라이팅 원고는 클라이언트 제공본 기준으로 배치합니다.
5) BI 항목: 현재 정의된 지표가 무엇인지 확인한 뒤, 5일 안에 끝나는 범위(지표 3~5개 조회 화면 또는 리포트 1종)로 한정합니다.

제외할 범위
- 신규 기능 개발, 기존 기능 로직 수정(공고에 명시된 대로 손대지 않습니다).
- 브랜드 디자인 신규 제작(로고·CI·BI 가이드), 다국어, 결제·정산 연동.
- 앱스토어 배포, 마케팅 자동화 도구 연동.

D1 (11.24) 서버 접속 정보·도메인·DB 덤프 인수, 배포 환경 확정. 산출물: 환경 정리표.
D2 (11.25) 운영 서버 배포 완료(웹·DB·정적 파일), HTTPS 연결. 산출물: 운영 URL.
D3 (11.26) Docker 이미지화 및 docker-compose 정리, CI 파이프라인 구성. 산출물: 파이프라인 설정 파일.
D4 (11.27) 화면 컴포넌트 마무리, 랜딩 페이지 제작. 산출물: 랜딩 URL, 수정 목록.

<리스크와 대응>
1) 서버·DB 접속 권한이 늦게 오는 경우 — 전체 일정이 그대로 밀립니다. 착수 첫날 오전에 접속 정보(서버 SSH, DB 덤프, 도메인 관리 계정)를 받는 것을 조건으로 잡았습니다. 늦어지면 D1을 로컬 환경에서 Docker 구성으로 대체하고 배포는 뒤로 미룹니다.
2) CI·BI의 의미가 두 갈래입니다. 지속적 통합(CI)과 지표(BI)라면 위 계획대로 5일 안에 끝납니다. 브랜드 아이덴티티(CI·BI)를 뜻한다면 디자인 리소스가 필요해 5일 범위를 넘습니다. 착수 전에 확정이 필요합니다.
3) 기존 기능을 건드리지 않는 조건이므로, 배포 중 발견한 기존 버그는 수정하지 않고 목록으로만 전달합니다. 범위가 늘어나면 별도 견적으로 처리합니다.
4) 지원자가 많은 공고라 판단 속도가 중요합니다. 미팅에서 위 1)·2)만 확정되면 당일 착수 가능합니다.

<기대 결과>
완료 시점에 클라이언트가 갖게 되는 것은 "내 PC에서만 돌던 서비스"가 아니라 "주소로 접속되고, 같은 방식으로 다시 배포할 수 있는 서비스"입니다. 배포 절차서가 남기 때문에 이후 기능을 추가할 때도 배포 담당자를 다시 찾을 필요가 없고, CI 파이프라인이 있으므로 수정→배포가 한 번의 푸시로 끝납니다. 랜딩 페이지와 지표 화면은 서비스 소개와 운영 판단에 바로 쓰는 상태로 전달합니다.

<확인이 필요한 질문>
1. CI·BI는 지속적 통합(CI)과 지표(BI)를 뜻하는지, 브랜드 아이덴티티(CI·BI)를 뜻하는지 확인 부탁드립니다. 전자면 5일 안에 포함, 후자면 디자인 리소스 협의가 필요합니다.
2. 서버는 이미 준비되어 있는지, 아니면 클라우드 계정부터 정해야 하는지 알려주세요. 후자면 인프라 비용은 클라이언트 부담입니다.
3. "화면 컴포넌트 마무리"의 구체 범위(화면 수, 수정 항목 목록)를 주실 수 있으면 D4 작업을 정확히 잡겠습니다.
4. 랜딩 페이지 원고·이미지는 제공되나요? 원고 작성이 필요하면 1일 추가됩니다.
5. 사전 검증 질문에 대한 답변이 필요하시면 위시켓 메시지로 안내 부탁드립니다.
