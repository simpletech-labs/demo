지원 내용 (본문)

Q1. 대부중개 사이트 구축 경험이 있는지 있음/없음으로 먼저.
없음입니다. 대부중개 도메인 사이트를 직접 구축한 실적은 없습니다. 대신 업체가 직접 가입해 상품과 서류를 올리고, 관리자가 승인해야 노출되는 구조의 광고·입점 플랫폼과 서류 검수 관리자 화면은 여러 건 구축했습니다. 미팅에서 화면으로 보여 드리겠습니다.

Q2. 업체 등록, 광고 상품 선택, 무통장 입금 확인, 관리자 승인으로 이어지는 흐름의 경험과 담당 범위.
입점 신청, 서류 업로드, 상품 선택, 입금자명 입력, 관리자 입금 확인과 노출 승인, 노출 기간 만료 처리까지 전 구간을 직접 개발했습니다. 담당 범위는 데이터 모델 설계, 승인 상태 전이 설계, 관리자 화면, 배포와 운영 문서입니다. 결제는 PG 없이 무통장 입금 확인 방식으로 처리했고, 입금자명과 신청 건이 자동으로 붙지 않는 경우를 관리자 화면에서 수동 매칭하도록 만들었습니다.

Q3. 미확정 범위에 대한 의견.
가. 등록증 OCR 완전 자동 승인은 권하지 않습니다. 추출 정확도가 95%여도 5% 오인식이 곧 미등록 업체 노출로 이어지고, 그 책임은 운영자에게 남습니다. OCR로 값만 채우고 관리자가 승인 버튼을 누르는 지금 방식을 유지하되, 추출 신뢰도가 낮은 필드를 빨간색으로 표시해 검수 시간을 줄이겠습니다.
나. 폐업·등록 변경 자동 반영은 부분만 가능합니다. 대부업 등록은 지자체 고시라 전국 통합 조회 API가 없습니다. 국세청 사업자 상태 조회 API로 휴·폐업은 자동 확인할 수 있고, 등록번호 유효기간 만료는 날짜 기준으로 자동 비노출 처리할 수 있습니다. 등록 내용 변경은 수동 확인이 남습니다. 자동 확인 결과를 관리자 목록에 표시하는 방식으로 제안합니다.
다. 맞춤 추천 노출 순서는 규칙 기반으로 하고, 같은 조건에서는 최근 갱신순과 무작위를 섞는 방식을 권합니다. 광고 등급 우선은 나중에 컬럼 하나 추가로 켤 수 있게 설계합니다.
라. 기존 소스를 보유하고 계시면 그것을 기준으로 견적을 다시 제시하는 편이 낫습니다. 없는 상태로 판단했습니다.

Q4. 500만원 범위에서 어디까지 가능한지.
1차 오픈 범위는 업체 목록(지역·상품 필터, 검색, 페이지네이션), 업체 상세(등록 정보·금리·한도·필수 고지 문구), 업체 회원가입과 정보·상품 등록, 서류 업로드와 OCR 값 채우기, 광고 상품 선택과 무통장 입금 안내, 관리자 승인·입금 확인·노출 관리, 대출 이자 계산기 1종, 공지·FAQ, 반응형 웹, 배포입니다. 이 범위가 500만원에 성립합니다.
제외되는 것은 맞춤 추천, 커뮤니티, 1:1 문의, 사기번호 검색, 불법금융 안내 페이지입니다. 이 다섯 개를 더하면 개발 범위가 약 2.5배가 되고 견적은 1,200만원 수준이 됩니다. 추천 기능만 나중에 붙인다면 질문·선택지 테이블과 업체 노출 조건 컬럼을 미리 비워 두어 2주에 추가할 수 있게 하겠습니다.

<프로젝트 진단>
이 사이트의 위험은 기술이 아니라 검수 책임입니다. 광고비를 받고 업체를 노출하는 구조라, 등록되지 않은 업체나 유효기간이 지난 업체가 한 번 노출되면 운영자 책임이 됩니다. 그래서 승인 상태를 신청·서류접수·검수중·승인·노출중·만료·반려로 나누고, 모든 상태 변경에 처리자와 시각을 남기겠습니다. 대부업 광고 표시 의무(등록번호, 최고이자율, 과도한 빚 경고)도 업체가 임의로 지울 수 없도록 상세 화면 하단에 고정 컴포넌트로 넣습니다.

<리스크와 대응>
첫째, 광고 상품과 가격표가 확정되지 않으면 관리자 화면의 상품 설정 구조를 두 번 만들게 됩니다. 착수 전에 상품 3~4종과 가격, 노출 위치를 확정해 주시면 그대로 데이터로 넣습니다. 둘째, 등록증 OCR 정확도는 서류 품질에 좌우됩니다. 스캔본이 아닌 사진이 올라오는 경우가 많아, 추출 실패 시 수기 입력으로 자연스럽게 넘어가는 흐름을 넣고 성공률을 관리자 화면에 표시합니다. 셋째, 표시 광고 규정입니다. 문구를 저희가 임의로 정하지 않고, 클라이언트가 확정한 문구를 고정 노출하며 변경 이력을 남깁니다.

<기대 결과>
업체는 가입 후 스스로 정보와 광고를 등록하고 입금하고, 운영자는 관리자 화면에서 입금 확인과 승인만 처리합니다. 등록번호가 만료된 업체는 자동으로 목록에서 내려가고, 상세 화면에는 법정 고지 문구가 항상 표시됩니다. 오픈 시점의 운영 인력은 대표 1명으로 충분한 상태를 목표로 합니다.

<확인이 필요한 질문>
1. 광고 상품은 몇 종이며 가격과 노출 위치가 정해져 있나요.
2. 대부업 등록을 받은 지자체와 등록번호가 있나요. 등록증 샘플 1건을 볼 수 있나요.
3. 기존에 보유한 사이트 소스나 기획 문서가 있나요.
4. OCR은 어느 수준까지 필요하신가요. 값 채우기까지인가요, 자동 승인까지인가요.
5. 도메인과 서버는 신규로 준비해야 하나요.
