지원 내용 * (2,999/5,000자)

Q1. 정산 정책이 겹칠 때는 "적용 순서표"를 먼저 문서로 확정하고, 그 순서를 코드가 아니라 데이터로 저장합니다. 순서는 ①제약사 기본 요율 ②제품별 프로모션 ③인센티브 ④최소 정산 기준 ⑤특별 정산(수기·이월)입니다. 계산은 단계별 중간값을 남기는 파이프라인으로 만들어, 한 건을 열면 "기본 요율 12% → 프로모션 -1% → 인센티브 +50만 → 최소 정산 미달 이월"이 순서대로 보입니다. 검증은 두 겹입니다. 과거 정산서 3개월치를 역산 입력해 원단위 일치를 확인하고, 조합 케이스 200건을 자동 대조합니다. 어긋난 건은 규칙·데이터·입력 중 어디서 갈렸는지 분류표로 남깁니다.
Q2. 촬영 각도와 양식이 일정하지 않은 문서에서 표를 읽는 작업을 해봤습니다. 배운 것은 인식률을 한 숫자로 올리려 하면 실패하고, "확실한 값만 자동으로 채우고 나머지는 사람이 빠르게 고치게" 만드는 쪽이 실제 오류를 줄인다는 점입니다. 필드 신뢰도에 임계값을 두어 상위는 자동 확정, 하위는 원본과 나란히 띄워 확인만 하게 했고, 숫자는 약가×수량=금액 검산으로 먼저 걸러냈습니다. 구체적 인식률은 실측 자료로 제출 시 정리하겠습니다.

<프로젝트 진단>
난이도는 화면 40개가 아니라 두 곳에 있습니다. 첫째, 정산 정책의 조합입니다. 제약사 70~80곳의 요율표 양식이 다르고 인센티브·최소 정산·프로모션이 겹치므로 "적용 순서"가 곧 정답입니다. 둘째, OCR입니다. 몇 년 전 인식률 60~70%로 접었다는 이력이 있으므로 모델 교체만으로는 부족하고, 촬영 품질 필터·병원 화면 유형 등록·빠른 수정 화면을 한 묶음으로 설계해야 합니다.

<작업 범위>
기술 스택 — 관리자 웹 React·TypeScript, 서버 Node.js API, DB PostgreSQL, 정산 계산은 분리 모듈, 딜러 앱은 한 코드베이스로 안드로이드·iOS를 함께 내는 Flutter, OCR은 클라우드 인식 API + 자체 후처리 조합입니다. 이유는 정산 이중 계산을 DB에서 막고, 앱을 한 번만 만들며, OCR 모듈을 교체 가능하게 두기 위해서입니다.
진행할 범위 — 기획·디자인(화면 설계 40화면, 정산 정책 적용 순서 정의서), 관리자 웹, 딜러 앱 2종, OCR 인식·확인·수정, 기준정보·권한, 정산 정책 관리, 실적 입력·검수, 지급·수취 정산, 세금계산서 관리, 분석·홈, 클라우드·백업, 데이터 이관·검증, 이관 절차서, 교육.
제외할 범위 — 홈택스 연동 발행(내역 관리까지), 컨설팅 알고리즘 자동화(우선순위 반영까지), 구매자 화면, OCR 모델 학습, 앱 계정·클라우드·OCR 이용료.
추가 제안(별도 견적) — ①과거 실적·정산 3년치 이관 6,000,000원/14일 ②요율표 자동 변환 12,000,000원/25일 — 권하지 않습니다. 양식 70~80종은 예외가 사람 손을 다시 타므로 기본은 통합 요율표 입력 + 엑셀 일괄 업로드로 두고 3개 양식군부터 적용을 권합니다. ③수취 정산서 원본 판독 5,000,000원/12일(상위 5개사) ④홈택스 연동 4,000,000원/8일. 운영·유지보수는 월 1,800,000원(평일 4시간 내 장애 대응, 월 1회 점검), 종료 시 2주 인계입니다.

<리스크와 대응>
가장 큰 불확실성은 OCR 정확도입니다. 60~70%로 접은 이력을 반복하지 않도록 네 단계로 나눕니다. ①촬영 단계에서 흔들림·기울기·해상도를 채점해 미달이면 재촬영을 요구합니다. ②병원별 처방 화면 유형을 템플릿으로 등록해 레이아웃을 좁힙니다. ③필드 신뢰도 임계값으로 자동 확정과 사람 확인을 나누고, 확인 화면은 원본 확대·숫자패드·이전 값 비교만 남겨 건당 수 초에 끝냅니다. ④약가×수량=금액, 보험코드·요양기관번호 검증으로 오인식을 자동 차단합니다. 목표치는 착수 4주 안에 골든셋 300장으로 측정해 숫자로 합의하고, 미달이면 엔진을 교체합니다. 두 번째는 요율표 70~80종 정규화입니다. 양식을 3개 군으로 묶어 우선 적용하고, 새 양식은 관리자 화면에서 매핑만 추가하면 되게 만듭니다. 세 번째는 오프라인 의사결정입니다. 구리시 방문을 격주로 잡고, 사이사이 결정할 항목은 목록으로 보내 하루 안에 회신받습니다.
