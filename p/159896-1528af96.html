  • 공개 정보 기준. 직원이 스마트폰으로 검수 항목·사진·부위별 판금·도막 수치를 입력하고, 관리자가 차량별 리포트 주소를 발급해 카카오 알림톡으로 발송하는 흐름. 지점 수와 검수 항목 표는 확인되지 않아 질문에 넣었습니다.

금액 근거

예상 금액 5,000,000원에서 95%를 부르면 일당이 15만원대로 떨어져 30일을 온전히 쓰는 계획이 성립하지 않습니다. 그래서 금액은 예산 상한에 맞추고 기간을 25일로 잡았습니다. 화면 수를 늘리지 않고 사내 입력 화면과 고객 리포트 두 개로 끝내는 조건이며, 그 대신 항목·지점 확장이 쉬운 구조로 만듭니다.

<프로젝트 진단>
이 시스템의 값은 리포트가 예뻐 보이는 데 있지 않고, 나중에 분쟁이 생겼을 때 근거로 쓰이는 데 있습니다. 중고차 검수 리포트는 판금·도막 수치와 사진이 판매 조건의 근거가 되므로, 입력한 값이 언제 누구에 의해 기록됐고 이후 바뀌지 않았는지가 남아야 합니다. 그래서 판단은 세 가지입니다. ①검수 결과는 입력 후 수정 대신 이력이 남는 방식으로 저장 ②리포트는 발급 시점의 값을 그대로 고정(이후 데이터가 바뀌어도 이미 보낸 리포트는 변하지 않음) ③부위별 수치와 사진을 같은 화면에서 대조할 수 있게 배치. 두 번째 판단은 입력 환경입니다. 직원이 현장에서 스마트폰으로 입력하므로, 사진 업로드가 느리거나 항목이 많으면 입력이 밀립니다. 항목을 단계로 나누고 사진은 백그라운드로 올리며 임시 저장이 되는 구조로 잡습니다. 세 번째는 발송입니다. 알림톡은 템플릿 사전 승인이 필요하고, 주소가 노출되면 안 되므로 추측 불가능한 토큰 주소로 발급합니다.

<작업 범위>
진행할 범위 — 검수 항목 표 정의(부위·항목·수치 단위), 사내 입력 화면(스마트폰 우선, 사진 촬영·업로드, 임시 저장, 검수 이력), 차량·고객 기본 정보 관리, 리포트 화면(모바일 우선, 부위별 수치와 사진, 종합 의견, 인쇄용 PDF), 리포트 주소 발급과 만료 설정, 카카오 알림톡 발송 연동(템플릿 승인 절차 포함), 관리자 화면(차량 목록·발송 이력·재발송), 지점 구분과 권한, 운영 매뉴얼.
제외할 범위 — 검수 항목의 전문적 기준 결정(현장 기준을 받아 구현), 카카오 비즈니스 채널 개설과 발신 프로필 승인(클라이언트 명의로 진행), 기존 시스템·ERP 연동, 재고·시세 조회, 앱스토어 배포용 네이티브 앱.
추가 제안 — 검수 항목 세트 여러 개 관리(차종·등급별), 고객 서명 확인, 리포트 열람 로그, 지점별 통계, 사진 워터마크·원본 보관 정책. 지금 함께 진행하거나 오픈 후 확장으로 붙일 수 있습니다.

<실행 플랜>
착수일 기준 25일입니다.
D1–D4 항목 표와 화면 정의. 검수 항목·부위·수치 단위를 표로 확정하고, 기존에 쓰는 종이 양식이 있으면 그대로 옮깁니다. 게이트 1: 항목 표 승인.
D5–D12 사내 입력 화면. 스마트폰 입력, 사진 업로드, 임시 저장, 이력 저장.
D13–D18 리포트와 발급. 모바일 리포트, 주소 발급·만료, PDF 출력.
D19–D22 알림톡 연동과 관리자 화면. 템플릿 승인 후 실제 발송 테스트.
D23–D25 검증과 인수인계. 실제 차량 3~5건으로 입력부터 고객 열람까지 통과 확인, 매뉴얼 전달.
총 공수 18영업일 / 25일(영업일 기준 약 18일)에서 버퍼를 남기고 역산했습니다. 검토 피드백은 3영업일 안에 반영하고, 늦어지는 만큼 이후 일정이 같이 밀립니다.

<리스크와 대응>
가장 먼저 확인할 것은 카카오 알림톡 발신 프로필과 템플릿 승인 상태입니다. 승인에 보통 며칠이 걸리고 반려되면 문구를 다시 올려야 하므로, D1에 신청을 시작해 개발과 병행합니다. 승인이 늦어지면 문자(SMS) 발송으로 먼저 오픈하고 알림톡은 승인 후 전환하는 경로를 준비합니다. 둘째, 현장 입력 속도입니다. 항목이 많으면 직원이 쓰지 않습니다. 항목 표를 확정할 때 실제 검수 1건에 걸리는 시간을 재고, 사진 업로드 방식(압축·순차 업로드)을 그에 맞춥니다. 셋째, 리포트 주소 유출입니다. 추측 불가능한 토큰과 만료 기간을 두고, 필요하면 열람 로그를 남깁니다. 넷째, 예산이 작아 범위가 좁습니다. 지점별 통계나 앱 배포는 이번 견적에 없으며, 필요하면 오픈 후 별도로 붙입니다.

<기대 결과>
완료 시점에 직원은 현장에서 스마트폰으로 검수 결과를 입력하고, 관리자는 차량별 리포트 주소를 만들어 알림톡으로 보냅니다. 고객은 링크 하나로 부위별 수치와 사진을 보고, 필요하면 PDF로 저장합니다. 나중에 "그때 이렇게 적혀 있었다"는 확인이 필요할 때 발송 시점의 리포트가 그대로 남아 있습니다.

<확인이 필요한 질문>
1. 검수 항목 표를 받을 수 있나요? 지금 쓰는 종이 양식이나 엑셀이 있으면 그대로 기준으로 삼겠습니다.
2. 지점이 몇 곳인가요? 지점별로 담당자 권한을 나눠야 하는지 확인하고 싶습니다.
3. 카카오 비즈니스 채널은 개설되어 있나요? 알림톡 템플릿 승인 이력이 있으면 알려주세요.
4. 사진은 1건당 몇 장 정도 찍으시나요? 저장·전송 정책에 영향을 줍니다.
5. 도막 수치는 측정기에서 나온 값을 사람이 입력하나요, 기기에서 자동으로 받을 수 있나요?
