<프로젝트 진단>
이 공고의 핵심은 디자인이 아니라 "노후 그누보드를 최신 환경으로 옮기면서 운영을 멈추지 않는 것"입니다. 그누보드는 오래된 PHP 버전에 맞춰 만들어진 경우가 많아, 서버 PHP 버전만 올리면 게시판·에디터·파일 업로드가 한꺼번에 깨집니다. 여기에 디자인을 그대로 유지한다는 조건이 붙으므로, 새로 만드는 것보다 기존 페이지 구조와 데이터를 정확히 옮기는 작업이 중심이 됩니다. 보안 취약점 해결이 목적이므로, 이관 후 취약점 점검과 관리자 권한 정리까지 포함해야 목적을 달성합니다.

<작업 범위>
진행할 범위
1) 현황 조사: 그누보드 버전·PHP 버전·설치된 플러그인·커스텀 스킨 목록화, 게시판·회원·첨부파일 데이터 규모 확인. 조사 결과표를 먼저 제출합니다.
2) 환경 이관: 최신 PHP·DB 환경 구성, 그누보드 최신 버전 이관, 커스텀 스킨 이식, 게시판·회원·첨부 데이터 이전.
3) 보안: 취약점 점검(관리자 계정·업로드 경로·SQL 처리·XSS), 불필요 관리자 계정 정리, HTTPS·보안 헤더 적용, 로그인 시도 제한.
4) 디자인 유지: 기존 페이지 레이아웃·이미지 그대로 재현(반응형 보정은 기존 비율 유지 범위), 모바일에서 깨지는 표·이미지 정리.
5) 이관·검증: 스테이징에서 전체 페이지 링크 점검, 운영 이관(점검 페이지 안내 하에 1회), 이관 후 2주 무중단 모니터링.
6) 유지보수: 이관 후 3개월 하자보수(보안 패치·오류 수정). 월 유지보수 계약은 별도.

제외할 범위
- 디자인 전면 개편, 신규 기능(예약·쇼핑몰·다국어) 추가.
- 영문 홈페이지(별도 운영 중) 작업.
- 서버 호스팅 계약·비용(클라이언트 명의).

<리스크와 대응>
1) 그누보드 커스텀 스킨이 많으면 이식 공수가 늘어납니다. 조사(D1~D4)에서 스킨·플러그인 수를 세고, 예상보다 2배를 넘으면 범위를 "핵심 5개 페이지 우선 이관 → 나머지 순차"로 바꿔 제안드립니다. 조사 결과를 먼저 보여드리는 이유입니다.
2) 첨부파일·게시글 데이터 손실 위험. 이관 전 전체 백업 2중화(서버 백업 + 별도 스토리지), 이관 후 글 수·첨부 수 대조표 제출.
3) PHP 버전 상향으로 구 플러그인이 동작하지 않을 수 있습니다. 대체 기능으로 재구현이 필요한 항목은 조사 단계에서 목록으로 확정합니다.
4) 운영 이관 시점의 짧은 접속 중단. 점검 페이지를 띄우고 공지 후 진행하며, 중단은 30분 이내로 맞춥니다.

<기대 결과>
완료 시점에 사이트는 최신 PHP·그누보드 환경에서 돌아가고, 관리자 화면에서 게시판·회원을 이전과 같이 관리할 수 있습니다. 노후 버전에서 비롯된 취약점 항목은 조치 결과표로 남고, 불필요한 관리자 계정이 정리되어 외부 침입 경로가 줄어듭니다. 디자인은 기존과 동일하므로 임직원·방문자가 체감하는 변화는 "빨라지고 안 끊기는 것"입니다.

<확인이 필요한 질문>
1. 현재 그누보드·PHP 버전과 호스팅 형태(자체 서버/호스팅사)를 알려주세요. 이관 난이도가 여기서 갈립니다.
2. 커스텀 스킨과 플러그인 개수를 대략이라도 알 수 있을까요? 조사 전 예상 공수를 잡는 데 필요합니다.
3. 리뉴얼 시점에 디자인을 100% 유지해야 하는지, 모바일만 보정해도 되는지 확인 부탁드립니다.
4. 운영 서버 접속 권한(SSH·DB·DNS)은 제공되나요? 권한이 없으면 이관 일정이 그만큼 밀립니다.
5. 하자보수 3개월 이후 유지보수 계약을 원하시면 월 단위 견적을 함께 드립니다.
